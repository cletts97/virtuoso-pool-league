# Virtuoso branding provenance

Inspected the official [Virtuoso website](https://virtuoso.tech/) on 19 October 2026. This is Virtuoso IT Limited, the managed IT/cloud/security services company, not a similarly named software or travel company.

The repository uses the site's actual logo files without redrawing them:

- `virtuoso-gradient.png`: [official gradient logo](https://virtuoso.tech/wp-content/uploads/2026/07/Logo_Gradient_PNG.png), used in the website's header.
- `virtuoso-white.png`: [official white logo](https://virtuoso.tech/wp-content/uploads/2026/07/Logo_White_PNG-2.png), used in the website's footer.

The [official theme stylesheet](https://virtuoso.tech/wp-content/themes/virtuoso-tech/style.css) includes `#101824`, `#080f1c`, `#ff5c00`, `#ff6b00`, and related orange accents. These inform the application's palette; supporting surfaces and status colours are application design choices, not claims about formal brand standards.

The pool-ball illustration is original CSS decoration. The pool-ball favicon is an application icon, not a fabricated Virtuoso corporate mark. The application uses system fonts; it makes no claim to use a licensed corporate typeface.

No branding asset is blocking the demo. For production polish, provide official SVG logo variants, the current brand guidelines (clear space/minimum size and colour specifications), and any approved webfont files/licence. Corporate logo ownership remains with Virtuoso.
